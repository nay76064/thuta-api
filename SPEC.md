# API feature spec

The API supports the product behavior in the [root specification](../SPEC.md).

- Provide account registration and sign-in.
- Provide public search, filtering, sorting, pagination, and detail retrieval for published listings.
- Provide authenticated owner operations for creating and managing the owner's listings.
- Provide administrator review actions for owner submissions.
- Return consistent errors that client interfaces can present safely.
- Serve launch locations, Buy/Rent listings, and MMK prices; support illustrative sample listings.
